# assetcraft MCP tools

Generated by `assetcraft tools --markdown`. Do not edit by hand: a test fails when this file
is out of date. Every tool is also a CLI verb (`assetcraft --help`). Dotted names (`app.verb`) are accepted.

| Tool | What it does | Required | Optional |
|---|---|---|---|
| `asset_status` | Counts, cost of active assets, licence seats, open deadlines, GWG limit. | - | - |
| `asset_add` | Register an asset. cost is the AfA base (net if VAT is deductible). GWG is automatic at or below the limit unless gwg=false. Life defaults from the category; cars need at least 8 years. | `tag`, `name`, `in_service`, `cost` | `category`, `gwg`, `holder`, `invoice_ref`, `life_years`, `location`, `notes`, `purchase_date`, `serial`, `supplier`, `warranty_until` |
| `asset_list` | List assets with book value at the start of this year. | - | `category`, `include_disposed`, `text` |
| `asset_show` | One asset with AfA schedule, postings to buchcraft, maintenance and deadlines. | `tag` | `as_of` |
| `asset_update` | Change fields; null clears serial/location/holder/warranty_until. cost/in_service/life_years/gwg are frozen once AfA was posted. | `tag` | `cost`, `gwg`, `holder`, `in_service`, `life_years`, `location`, `name`, `notes`, `serial`, `warranty_until` |
| `asset_dispose` | Retire an asset (sold, scrapped). Returns disposal-year AfA, book value and gain/loss. The asset becomes read-only. | `tag`, `date` | `note`, `proceeds` |
| `asset_afa_schedule` | Straight-line AfA plan in cents with Halbjahres-AfA and GWG. | `tag` | - |
