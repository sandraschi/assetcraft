# assetcraft v0.1.1

Hardware and licence inventory with an AfA schedule. Local, one SQLite file. Windows x64.

## Downloads

- `assetcraft-app.exe`: the desktop window.
- `assetcraft.exe`: CLI and MCP server.
- `assetcraft-0.1.1-setup.exe`: per-user installer.
- `assetcraft-v0.1.1.mcpb`: MCP bundle.

## What is new

- The window menu is File, Edit, View, Window, and Help.
- A `candidate.hired` event from hirecraft records an equipment reminder. It does not invent a purchase.
